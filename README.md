# Алмазная мозаика по фото — лендинг приёма заказов

**Живой сайт: [https://am-52.ru](https://am-52.ru)** — коммерческий лендинг реального бизнеса
(производство алмазной мозаики по фото, Нижний Новгород).

Сайт принимает заказы 24/7: клиент загружает фото, выбирает размер —
заявка приходит владельцу на почту со ссылкой на сохранённое фото.

## Кейс

**Проблема.** Бизнес принимал заказы в личке группы ВК и по телефону:
заявки терялись, цены отправлялись вручную, нет приёма заявок 24/7,
нет единой витрины работ, цен и ответов на вопросы.

**Решение.** Одностраничный лендинг с полным циклом продажи:
преимущества → шаги → состав набора → таблица цен → галерея работ с
подписями → отзывы → FAQ → форма заказа с загрузкой фото.
Заявки автоматически приходят на почту, фото сохраняются на сервере.

**Результат.**
- Сайт в продакшене: домен, хостинг, SSL Let's Encrypt (оба зеркала: am-52.ru и www.am-52.ru)
- Сквозной конвейер заявки: форма → валидация → AJAX → PHP → фото на сервере → письмо владельцу
- SEO: robots.txt, sitemap.xml, Яндекс.Вебмастер (права подтверждены, регион назначен)
- 152-ФЗ: политика конфиденциальности + согласие в форме

## Что умеет

**Фронтенд**
- Адаптивная вёрстка (десктоп / планшет / мобильный), бургер-меню
- Липкая навигация, плавный скролл по якорям
- Галерея 12 работ с подписями «тип работы + размер»
- Валидация формы: имя, телефон (10–11 цифр), размер, фото до 20 МБ, согласие;
  сводка незаполненных полей одним сообщением
- AJAX-отправка без перезагрузки, защита от двойного клика

**Бэкенд (PHP)**
- Серверная валидация всех данных
- Сохранение фото в `uploads/` под уникальными именами (дата + случайный код)
- Защита `uploads/` от выполнения PHP (.htaccess)
- Письмо владельцу: имя, телефон, размер, комментарий + ссылка на фото
- JSON-ответы фронту (успех / ошибка)

## Стек

- HTML5, CSS3 (custom properties, grid, flexbox), vanilla JavaScript (fetch API)
- PHP 8.3 (загрузка файлов, mail(), JSON)
- Git + GitHub
- Хостинг Reg.ru (ISPmanager, Apache + PHP FastCGI)
- Let's Encrypt, Яндекс.Вебмастер

## Конвейер заявки

```
Клиент заполняет форму + загружает фото
        ↓  fetch POST
php/send.php: серверная валидация
        ↓
Фото → uploads/photo-YYYYmmdd-His-xxxx.jpg  (защита .htaccess)
        ↓
Письмо владельцу: данные + ссылка на фото
        ↓
JSON → зелёное сообщение «Заявка отправлена»
```

## Безопасность

- Никаких паролей и ключей в коде (отправка mail() от имени собственного домена)
- Whitelist расширений (jpg/jpeg/png/webp) + проверка getimagesize()
- Уникальные имена файлов на сервере, запрет выполнения PHP в uploads/
- Валидация на клиенте и на сервере

## Запуск локально

git clone https://github.com/PavlenkoSergeySerg/mozaika-landing.git
