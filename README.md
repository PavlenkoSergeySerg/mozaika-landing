# Алмазная мозаика по фото — лендинг приёма заказов

**Живой сайт: https://am-52.ru** — коммерческий лендинг реального бизнеса

Проблема: заказы терялись в личке ВК и по телефону, нет витрины цен и приёма 24/7.
Решение: одностраничник с полным циклом продажи и формой с загрузкой фото.
Результат: продакшен с защитой загрузок, анти-спамом, подписанной почтой
(SPF/DKIM/DMARC), разметкой SEO/AIO/GEO и PageSpeed 87/100.

- Адаптив + бургер + липкая кнопка «Заказать» на мобильных (цель mobile_cta_click)

- PHP: серверная валидация, finfo-MIME, уникальные имена, лог вне webroot,
  письмо с Reply-To клиента
- Метрика: order_sent, mobile_cta_click; Вебвизор с маскировкой ПД
- SEO/AIO/GEO: llms.txt, ai.txt, JSON-LD (Service+FAQ+Review), абсолютные OG

HTML5/CSS3/vanilla JS; PHP 8.3; Reg.ru (nginx front + Apache backend);

honeypot+rate-limit; лог вне webroot; ПД замаскированы; деплой через deploy.ps1.
